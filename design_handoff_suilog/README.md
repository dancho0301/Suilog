# Handoff: Suilog リデザイン

## Overview

水族館訪問記録アプリ「Suilog」のUIリデザインです。  
既存アプリをよりシンプル・フレンドリーな印象に刷新することを目的としています。

明るい水色ベースのカラーパレット、フラットでかわいいイラスト、角丸を多用したカード型UIが特徴です。

---

## About the Design Files

`Suilog Redesign.html` は **HTMLで作成したハイファイデザインプロトタイプ** です。  
このファイルをそのまま本番に使うのではなく、既存のアプリ（React Native / Swift / Kotlin など）の環境・パターンに合わせて **このデザインを再現する** のがゴールです。

- インタラクション・画面遷移のデモとして参照してください
- デザイントークン（色・フォント・間隔）は本ドキュメントに記載しています

---

## Fidelity

**ハイファイデリティ（Hi-fi）**  
色・タイポグラフィ・スペーシング・インタラクションまで作り込んでいます。  
開発者はこのデザインを **ピクセル精度で** 既存コードベースに再現してください。

## 画面一覧

### 1. マイ水槽（ホーム）

**目的**: ユーザーの水槽ビジュアルと訪問サマリーを表示するメイン画面。

**レイアウト**:
- 縦スクロール、左右 20px パディング
- ヘッダー: 「こんにちは 👋」サブテキスト + 「マイ水槽」大見出し + アバターアイコンボタン（右）
- 水槽カード: 角丸なしで横幅100%。上部にSVGアニメーション水槽（魚・くらげ・珊瑚・海草）、下部に統計バー（訪問水族館数 / 生き物数 / 訪問回数）
- 「最近の訪問」セクション: セクションヘッダー + 「すべて見る」リンク + 訪問カードリスト

**水槽カード統計バー**:
- 白背景、3カラム均等
- 数値: 24px / 800weight / primary色
- ラベル: 11px / `#AABBC4`

**訪問カード（最近の訪問）**:
- 白背景、radius 18px
- 左: emoji アイコン（50×50px、radius 16px、primaryBg背景）
- 中: 水族館名（15px/600）+ 日付（12px/#AABBC4）
- 右: 星評価（#F5B942）

---

### 2. マップ

**目的**: 水族館の地図表示と近くのリスト。

**レイアウト**:
- 検索バー（白カード、radius 14px）
- 地図エリア（radius 20px、高さ240px）: 訪問済みは primary色の丸ピン、未訪問は白ピン + accent色の通知ドット
- 凡例オーバーレイ（右下）: 半透明白背景
- 「近くの水族館」リスト: 横スクロール可能カード

---

### 3. 訪問記録リスト

**目的**: 過去の訪問記録一覧。

**レイアウト**:
- ヘッダー右に「+ 追加」ボタン（primary色、radius 20px）
- カード（radius 20px）:
  - 上段: emoji + 水族館名 + 日付 + 星評価
  - 中段: **ゴールド🥇 / シルバー🥈 チェックインバッジ**（pill形状）
  - 下段: メモテキスト（primaryBg背景、radius 12px）

**チェックインバッジ pill**:
- radius: 20px、padding: 3px 10px
- ゴールド: 背景 `#FFF8E6`、ボーダー `#F5C842`、テキスト `#B8860B`
- シルバー: 背景 `#F4F4F4`、ボーダー `#CFD8DC`、テキスト `#7A90A0`

---

### 4. 訪問記録詳細（新規追加）

**目的**: 新しい訪問記録を追加するフォーム画面。

**フィールド一覧（上から順）**:

1. **チェックイン方法**（新規）
   - 2択ボタン: 「📍 ゴールド（位置情報）」/ 「📷 シルバー（写真Exif）」
   - 選択中: 白背景、primary色2pxボーダー、box-shadow
   - 非選択: `#F8FAFB`背景、`#E8EEF2`ボーダー
   - シルバー選択時: 「写真Exifが1km圏内ならゴールド相当」の補足メモ表示（#FFF8E6背景）

2. **水族館名** — セレクタ風カード（タップで検索画面へ）

3. **訪問日** — 日付ピッカー（カレンダーアイコン付き）

4. **評価** — 5段階星ボタン（タップでON/OFF、選択中はscale 1.15）

5. **メモ** — テキストエリア（min-height 100px）

6. **写真** — 点線ボーダーのアップロードエリア（radius 14px）

7. **保存ボタン** — 「記録を保存する 🐠」、primary色、幅100%、radius 16px

---

### 5. 水族館詳細ページ

**目的**: 個別水族館の情報と、そこへの訪問記録導線。

**レイアウト**:
- ヒーロー: 水槽SVGビジュアル（高さ220px）、左上に戻るボタン（半透明白、blur）
- 水族館名（22px/800）+ 所在地（13px/#AABBC4）+ 星評価バッジ
- 「+ 訪問を記録する」CTA（primary色、幅100%）
- 情報カード（営業時間・料金・電話）: 白背景、radius 18px、各行 icon + ラベル + 値
- 「見られる生き物」グリッド（2カラム）: 各カード radius 14px、emoji + 名前 + 説明

---

### 6. プロフィール

**目的**: ユーザーの実績・バッジ一覧。

**レイアウト**:
- ヒーロー: primaryグラデーション背景、アバター円（80px）+ 名前 + ランク
- 統計バー（3カラム）: 訪問館数 / ゴールド×シルバー内訳 / バッジ数
- 「獲得したバッジ」: 3カラムグリッド、各バッジ radius 16px、primaryLight ボーダー、右下に primary色のチェックマーク
- 「挑戦中のバッジ」: リスト形式、アイコン + 名前 + 進捗テキスト + プログレスバー
  - プログレスバー: 高さ6px、背景 `#EEF4F8`、fill `primary → primaryLight` グラデーション
- 「バッジをシェアする」ボタン: アウトライン型（white背景、primaryLight ボーダー）

## チェックインシステム

| 種別 | 条件 | ランク |
|---|---|---|
| 位置情報チェックイン | GPS で現地確認 | 🥇 ゴールド |
| 手動チェックイン（Exif一致） | 写真ExifのGPSが水族館から1km圏内 | 🥇 ゴールド同等 |
| 手動チェックイン（Exif不一致） | 上記以外の写真 or 写真なし | 🥈 シルバー |

## タブバー

4タブ構成（左から）: マイ水槽 / マップ / 記録 / プロフィール

- アクティブ: primary色アイコン + primary色テキスト（10px/600）
- 非アクティブ: `#C0C0CC` アイコン + `rgba(60,60,67,0.5)` テキスト
- 背景: `rgba(255,255,255,0.92)` + `backdropFilter: blur(16px)`
- 上ボーダー: `0.5px solid rgba(0,0,0,0.08)`
